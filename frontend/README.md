## Tech stack
React (Vite) + Express + PostgreSQL (Supabase). Deploy: Vercel (frontend) + Render (backend).

## Funktioner
**Kund:** se produkter, lägga i varukorg, genomföra köp.
**Admin:** skyddad inloggning, hantera produkter, se/ändra orderstatus.

## Köra lokalt
cd Backend && npm install && node server.js
cd frontend && npm install && npm run dev
